# VR Trash Collection Simulator

Hackathon Prototype | Meta Quest 3 | Unity

## Overview

This project was developed during a hackathon as a proof-of-concept exploring how virtual reality could be used to simulate and evaluate solutions for urban waste collection. 
The prototype places the user in control of an RC-style vehicle capable of collecting trash in a virtual environment, allowing rapid experimentation with interaction 
design and operational concepts.

The goal was to investigate how immersive technologies could support the development and testing of ideas aimed at improving cleanliness and waste management within local communities.

## Challenges

One of the largest challenges was the rapid iteration cycle required for VR development. Because every test required building and deploying to the Meta Quest 3, each iteration took approximately two minutes before feedback could be gathered.

Working within a roughly 10-hour development window required careful prioritization, continuous testing, and rapid problem solving to produce a functional prototype before the end of the event.
